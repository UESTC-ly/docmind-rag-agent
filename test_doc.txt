DocMind 系统架构介绍

一、整体架构
DocMind 是一个基于 RAG 和 Agent 编排的文档智能系统。系统分为四层：API 层、Agent 编排层、Skills 技能层和存储层。

二、API 层
API 层使用 FastAPI 框架，提供异步接口。主要包括用户鉴权、文档管理和 Agent 对话三大模块。鉴权采用 JWT 令牌机制。

三、Agent 编排层
Agent 编排层是系统核心。它接收用户请求，通过大语言模型的 Function Calling 能力，自主决定调用哪些技能。编排器采用感知-规划-行动-观察的主循环。

四、Skills 技能层
技能层是可插拔设计。当前包含五个技能：知识库检索、思维导图生成、关系图谱抽取、报告生成和联网搜索。新增技能只需继承 BaseSkill 基类并注册。

五、存储层
存储层由四个组件构成：PostgreSQL 存储用户和文档元数据，Qdrant 存储文档向量，Redis 作为任务队列，Celery 负责文档的异步解析。

六、数据流
用户上传文档后，Celery 异步解析文档并分块，调用 Embedding 模型向量化，存入 Qdrant。用户提问时，系统检索相关片段，交给大模型生成答案。
